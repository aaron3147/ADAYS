# ADAYS

Sprint 1 foundation.

## Vision
A lightweight tutoring scheduling system centered on monthly snapshots, attendance, and billing.

## Core principles
- Scheduling equals enrollment.
- Monthly Snapshot is the source of truth.
- Excel is used to create/update snapshots.
- Billing is derived from scheduled sessions.

## Sprint 1 deliverables
- Project documentation
- Database design
- Snapshot architecture
